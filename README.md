# AO Tyrnavos 2005 Website

Αυτό είναι έτοιμο static site για GitHub + Netlify + CloudCannon.

## Τι αλλάζεις εύκολα
Άνοιξε το αρχείο `data/site.json` από το CloudCannon Data Editor και αλλάζεις:
- κείμενα αρχικής
- νέα
- αγώνες
- στοιχεία ακαδημίας
- χορηγούς
- στοιχεία επικοινωνίας

## Αυτόματο ανέβασμα
CloudCannon -> Save/Publish -> κάνει commit στο GitHub -> Netlify κάνει αυτόματο deploy -> το site ενημερώνεται.
